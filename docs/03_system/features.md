# 機能一覧

**Document Version** : 1.1

**更新日** : 2026/08/05

本ドキュメントは、システム全体の機能を俯瞰するための一覧です。

---

## 1. 目的

- システムに含まれる機能の全体像を把握する
- 機能追加・変更時の起点とする
- 画面一覧・テーブル一覧への起点とする

---

## 2. 機能一覧

|機能ID|機能名|概要|備考|
|---|---|---|---|
|CMN|共通|共通レイアウト、TOP画面||
|EMP|社員管理|社員の検索・一覧・登録・編集・削除|Version 1.0 の題材機能|
|DEP|部署管理|部署の検索・一覧・登録・編集・削除||

## 4. 備考

- 機能IDは画面IDの先頭3文字と一致させます（例：`EMP001` の `EMP`）。画面一覧に機能ID列は設けません。
- 機能の詳細仕様は、本一覧ではなく各画面設計書・テーブル定義書等に記載します。
- 作業の進捗・完了状態は [`progress.md`](../01_project/progress.md) を正とします。本一覧に「状態」列は設けません。
- **掲載タイミング**: 実装することが決まった時点で本一覧へ追加する（設計・実装の完了は待たない）。目安は [`progress.md`](../01_project/progress.md) に該当 PRG を切ったとき、または Version スコープに含めたとき。画面・テーブルは後続で [`screens.md`](screens.md)・[`tables.md`](tables.md) へ載せる。
