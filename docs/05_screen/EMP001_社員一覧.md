# EMP001 社員一覧

**Document Version** : 1.0

**更新日** : 2026/07/30

## 1. 基本情報

|項目|内容|
|----|----|
|画面ID|EMP001|
|画面名|社員一覧|
|画面種類|一覧|
|概要|社員情報を検索・一覧表示し、対象社員を選択して編集画面へ遷移する画面です。|
|権限|未定|

---

## 2. 画面の目的

- 社員を検索・一覧表示する
- 対象社員を選択し、編集画面（EMP002）へ遷移する

---

### 8.5 データ取得

- 部署名は、社員マスタ（`employee`）と部署マスタ（`department`）を `department_id` で **LEFT JOIN** し、`department.deleted_flg = false` のレコードから取得する。取得できない場合は画面で `-` を表示する。
- 状態の表示名称は、社員マスタ.`status_code` を共通コードマスタ（`common_code`）の `EMPLOYEE_STATUS` から **LEFT JOIN** し `code_name` に変換して表示する。JOIN 条件には `deleted_flg = false` を含める。取得できない場合は画面で `-` を表示する。
- 部署の検索条件は、画面では部署名を選択し、内部では `department_id` で絞り込む。
- 状態の検索条件は、画面では在籍・休職・退職の名称を選択し、内部では `status_code`（`ACTIVE` / `LEAVE` / `RETIRED`）で絞り込む。
- 社員番号・氏名の検索では、`%`・`_`・`\` をワイルドカードとして扱わず、通常の文字として検索する（SQL 側でエスケープする）。
- 社員番号リンクの引き継ぎキーは社員ID（`employee_id`）とする。
- 部署プルダウンの選択肢は、部署マスタから `deleted_flg = false` のレコードを `display_order` 昇順、`department_code` 昇順で取得する。
- 状態プルダウンの選択肢は、共通コードマスタから `code_type = 'EMPLOYEE_STATUS'` かつ `deleted_flg = false` のレコードを `display_order` 昇順、`code` 昇順で取得し、先頭に「すべて」を追加する。

### 8.6 画面レイアウト（一覧 GET）

[`docs/02_rules/ui.md`](../02_rules/ui.md) §3.7 の初適用例です。共通方針は同節を正とし、本節には EMP001 固有の実装情報のみを記載します。

|項目|内容|
|----|----|
|テンプレート|[`src/main/resources/templates/employee/list.html`](../../src/main/resources/templates/employee/list.html)|
|画面固有 JS|[`src/main/resources/static/js/employee/list.js`](../../src/main/resources/static/js/employee/list.js)|
|共通 CSS|[`src/main/resources/static/css/common.css`](../../src/main/resources/static/css/common.css)（DataTables 表示補正）|

#### ページ上部

- 左: パンくず（TOP（リンク） / 社員管理（テキスト） / 社員一覧（現在位置））。[`fragments/breadcrumb-employee.html`](../../src/main/resources/templates/fragments/breadcrumb-employee.html) で表示する
- 右: 新規登録ボタン
- `h1`（社員一覧）は `visually-hidden`

#### メッセージエリア

- ページ上部の直後・検索エリアの前に配置する
- Flash 属性 `successMessage` があるときのみ Bootstrap `alert alert-success alert-dismissible` を表示する（[`docs/02_rules/ui.md`](../02_rules/ui.md) §7 の Version 1.0 暫定）
- 検索・クリア等の通常 GET では表示しない（flash は 1 リクエスト限り）

#### 検索フォーム

- PC 幅（`xl` 以上）: 社員番号・氏名・部署・状態・ボタンを横並びに近い配置
- 中幅（`md` 以上）: 2 列で折り返し
- 狭い幅: 1 列で縦積み
- ラベルと `id` / `for` の対応、バリデーション表示を維持する

#### 一覧表

- 操作列は設けない。
- 社員番号列はリンク表示とする。遷移先は `GET /employee/{employeeId}/edit`。

#### DataTables 初期化（EMP001 固有）

|設定|値|
|---|---|
|テーブル id|`employee-list-table`|
|`pageLength`|`10`|
|初期ソート|0 列（社員番号）昇順|
|`dom`|表示件数・件数表示を左、ページングを右。一覧表上部のみ|

## 10. 備考

- 画面固有コンテンツは Main 領域に配置する（[`docs/02_rules/ui.md`](../02_rules/ui.md) §2.3）。
- ページ上部・検索・一覧のレイアウト方針は [`docs/02_rules/ui.md`](../02_rules/ui.md) §3.7 を参照する。EMP001 固有の実装は §8.6 を参照する。
- 一覧の表示対象は、社員マスタ.削除フラグが未削除のレコードとする。
- 在籍区分が退職の社員も一覧に含める。状態の検索条件で絞り込める。
- 検索条件が未指定の項目は条件に含めない（「すべて」選択時も同様）。
- ページング・列ソートの共通方針は [`docs/02_rules/ui.md`](../02_rules/ui.md) §3 に従う。ページサイズ初期値は同 §3.5 のデフォルト（10件）とする。
- 更新・削除は EMP002 の編集画面から行う（[`docs/07_decisions/employee_list_navigation_pattern.md`](../07_decisions/employee_list_navigation_pattern.md) 参照）。
- 登録・更新・削除成功時のメッセージ表示は §5.1a・§8.6 を参照する（Version 1.0 暫定。共通方針の完全版は [`BLG-CMN-001`](../01_project/backlog.md)）。
- データ取得の詳細は §8.5 を参照する。
