# 画面設計書テンプレート

**Document Version** : 1.0

**更新日** : 2026/07/30

本テンプレートは画面設計書として利用します。

**基本方針**

- 「読み手が理解しやすいこと」を最優先とします。
- 同じ情報はできるだけ一か所で管理し、二重管理を避けます。

**画面設計方針**

- 1画面につき1ファイルで管理します。
- 章構成はテンプレートで統一します。
- 各章の記載方法は推奨する記載例を参考に、設計者が最も分かりやすい方法を選択してください。
- 本設計書は「画面設計書兼簡易詳細設計書」として運用します。クラス図・シーケンス図のような詳細な設計図表は作成せず、§8「実装情報」でエントリポイント・使用クラス・使用テーブル・使用APIを整理することで、実装時に参照できる最小限の詳細設計を兼ねます。
- §1〜§7は画面仕様（何を実現する画面か）、§8は実装情報（どこに実装するか）として役割を分離します。両者を混在させないでください。
- 画面種類ごとの UI 共通方針は [`docs/02_rules/ui.md`](../02_rules/ui.md) を参照してください。一覧画面のページング・ソート等は画面設計書に詳細を繰り返さず、同ドキュメント §3 を正とします。
- §5「画面項目」の DB項目欄は、原則として `テーブル論理名.カラム論理名`（例：`社員マスタ.社員番号`）を使用します。物理名はテーブル定義書を正とし、JOIN 条件・コード変換・内部キー・更新内容等の実装情報は §8 に記載します。

**テンプレート利用方法**

- 引用（>）で記載されている内容は説明・記載例です。実際の設計内容は引用の外側に記載し、説明・記載例は完成した設計書から削除してください。
- 必要に応じて、見出し・表・説明などを追加・修正・削除してください。

※テンプレートは実際の運用を通して継続的に改善してください。
