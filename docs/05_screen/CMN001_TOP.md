# CMN001 TOP

**Document Version** : 1.0

**更新日** : 2026/07/30

## 1. 基本情報

|項目|内容|
|----|----|
|画面ID|CMN001|
|画面名|TOP|
|画面種類|その他|
|概要|アプリの起点となる画面。機能への入口と、スターターキットのデモ画面としての位置づけを示す。|
|権限|未定|

---

## 2. 画面の目的

- アプリの起点（ルート）として機能入口を提供する
- Version 1.0 の題材機能（社員管理）への導線を示す

---

## 3. 画面イメージ

共通レイアウト（Header / Sidebar / Main）の Main 内の構成イメージです（[`docs/02_rules/ui.md`](../02_rules/ui.md) §2 参照）。

**パンくずは表示しない**（ルート画面のため。方針は [`ui.md`](../02_rules/ui.md) §2.3）。

~~~text
----------------------------------------------------------------------------------------------
【導入】

TOP
業務システム開発で利用しやすい Spring Boot スターターキットのデモ画面です。
----------------------------------------------------------------------------------------------
【機能入口】

+-------------------------------+
| 社員管理                      |
| 社員情報の一覧・検索・登録・  |
| 更新・削除を行う画面です。    |
| [社員管理を開く]              |
+-------------------------------+
----------------------------------------------------------------------------------------------
~~~

---

## 4. 画面構成

|No.|エリア名|内容|備考|
|---|--------|----|----|
|1|導入|画面タイトル（visible）と短い説明|パンくずは置かない。現在地は見出しで示す|
|2|機能入口|利用可能な機能へのカード導線|Version 1.0 では社員管理のみ|

---

## 5. 画面項目

### 5.1 導入

|名称|DB項目|種類|備考|
|----|------|----|----|
|TOP||見出し（visible `h1`）|現在地を示す。パンくずは用いない|
|説明||テキスト|スターターキットのデモ画面である旨|

### 5.2 機能入口

|名称|DB項目|種類|備考|
|----|------|----|----|
|社員管理||カード見出し|機能名|
|機能説明||テキスト|社員管理でできることの短い説明|
|社員管理を開く||ボタン（リンク）|EMP001（社員一覧）へ遷移する|

|名称|内容|遷移先|備考|
|----|----|------|----|
|社員管理を開く|社員一覧を表示する|EMP001||
