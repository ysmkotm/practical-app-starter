# DEP001 部署一覧

**Document Version** : 1.0

**更新日** : 2026/08/05

## 1. 基本情報

|項目|内容|
|----|----|
|画面ID|DEP001|
|画面名|部署一覧|
|画面種類|一覧|
|概要|部署情報を検索・一覧表示し、対象部署を選択して編集画面へ遷移する画面です。|
|権限|未定|

---

## 2. 画面の目的

- 部署を検索・一覧表示する
- 対象部署を選択し、編集画面（DEP002）へ遷移する

---

## 3. 画面イメージ

共通レイアウト（Header / Sidebar / Main）の Main 内の構成イメージです（[`docs/02_rules/ui.md`](../02_rules/ui.md) §2 参照）。

~~~text
----------------------------------------------------------------------------------------------
【ページ上部】

TOP / 部署管理 / 部署一覧                                    [新規登録]
----------------------------------------------------------------------------------------------
【メッセージエリア】（登録・更新・削除成功直後のみ）

[部署を登録しました。                                    ×]
----------------------------------------------------------------------------------------------
【検索エリア】

部署コード [    ]  部署名 [    ]  [検索] [クリア]
（PC 幅では横並び。狭い幅では折り返す）
----------------------------------------------------------------------------------------------
【一覧エリア】

[10件表示] 8件中1から8まで表示                              [前] 1 [次]
+------------------------------------------------------------------------------+
| 部署コード  | 部署名   | 表示順 |
+------------------------------------------------------------------------------+
| DEP001      | 営業部   | 1      |
| DEP002      | 開発部   | 2      |
| DEP003      | 総務部   | 3      |
+------------------------------------------------------------------------------+
（部署コードはリンク表示）
（DataTables コントロールは一覧表の上部のみ。下部には表示しない）
----------------------------------------------------------------------------------------------
~~~

## 8. 実装情報

### 8.1 エントリポイント

#### 一覧表示・検索

|項目|内容|
|----|----|
|URL|`/department`|
|HTTPメソッド|GET|
|テンプレート|`src/main/resources/templates/department/list.html`（新規作成）|
|Controller|`DepartmentController#showList`（新規作成）|

- 検索条件は `DepartmentSearchForm`（新規作成）で受け取る（GET・クエリパラメータ）。
- Mapper は検索条件に合致する全件を返却する（EMP001 と同様、Version 1 では SQL にページング条件を付けない。[`docs/02_rules/ui.md`](../02_rules/ui.md) §3.4、[`docs/02_rules/coding.md`](../02_rules/coding.md) §7 参照）。
- 一覧表は DataTables で初期化する（[`docs/02_rules/ui.md`](../02_rules/ui.md) §3.6 参照）。

### 8.5 データ取得

- 一覧表示対象は部署マスタ（`department`）の `deleted_flg = false` のレコードとする。
- 初期表示順は `display_order` 昇順、同順位は `department_code` 昇順とする（部署マスタ自体の想定用途に合わせる）。
- 部署コード・部署名の検索では、`%`・`_`・`\` をワイルドカードとして扱わず、通常の文字として検索する（SQL 側でエスケープする。EMP001 の方針を踏襲）。
- 部署コードリンクの引き継ぎキーは部署ID（`department_id`）とする。

---

### 8.6 画面レイアウト（一覧 GET）

[`docs/02_rules/ui.md`](../02_rules/ui.md) §3.7 の適用例です。共通方針は同節を正とし、本節には DEP001 固有の実装情報のみを記載します。EMP001（[`EMP001_社員一覧.md`](EMP001_社員一覧.md) §8.6）と同じ構成方針を踏襲します。

|項目|内容|
|----|----|
|テンプレート|`src/main/resources/templates/department/list.html`（新規作成）|
|画面固有 JS|`src/main/resources/static/js/department/list.js`（新規作成）|
|共通 CSS|[`src/main/resources/static/css/common.css`](../../src/main/resources/static/css/common.css)（DataTables 表示補正）|

#### ページ上部

- 左: パンくず（TOP（リンク） / 部署管理（テキスト） / 部署一覧（現在位置））。EMP001 の `breadcrumb-employee.html` に相当する部署管理用 fragment を新設するか、共通化するかは実装時に判断する（軽微な判断のため、専用の判断記録は作らずコード実装時のコメント・PR説明で足りる）
- 右: 新規登録ボタン
- `h1`（部署一覧）は `visually-hidden`

#### メッセージエリア

- ページ上部の直後・検索エリアの前に配置する
- Flash 属性 `successMessage` があるときのみ Bootstrap `alert alert-success alert-dismissible` を表示する（EMP001 の Version 1.0 暫定方針を踏襲）
- 検索・クリア等の通常 GET では表示しない（flash は 1 リクエスト限り）

#### 検索フォーム

- PC 幅（`xl` 以上）: 部署コード・部署名・ボタンを横並びに近い配置
- 中幅（`md` 以上）: 2 列で折り返し
- 狭い幅: 1 列で縦積み
- ラベルと `id` / `for` の対応、バリデーション表示を維持する

#### 一覧表

- 操作列は設けない（EMP001 と同じ画面遷移方針。[`employee_list_navigation_pattern.md`](../07_decisions/employee_list_navigation_pattern.md) 参照）。
- 部署コード列はリンク表示とする。遷移先は `GET /department/{departmentId}/edit`。

#### DataTables 初期化（DEP001 固有）

|設定|値|
|---|---|
|テーブル id|`department-list-table`|
|`pageLength`|`10`|
|初期ソート|2 列（表示順）昇順|
|`dom`|表示件数・件数表示を左、ページングを右。一覧表上部のみ|
