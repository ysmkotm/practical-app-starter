# プロジェクト概要

**Document Version** : 1.2

**更新日** : 2026/08/02

---

## 1. プロジェクトの目的

本プロジェクトは、**AIとの協調開発**を前提とした、**システム開発スターターキット兼リファレンスプロジェクト**の作成を目的とします。

Version 1.x では Spring Boot を採用し、社員管理システムを題材として実装を進めます。社員管理システムはあくまで題材であり、その開発自体を目的とするものではありません。業務システム開発でそのまま利用・流用できる構成・設計・実装例を提供します。

本スターターキットは、実務で利用される構成・設計・実装方針を取り入れ、学習用途だけでなく、**実案件でも活用しやすい品質** を目指します。

また、本プロジェクトでは、**ソースコードだけでなく開発ドキュメントも成果物の一部** と考えます。

設計・実装・開発ドキュメントを同じ重要度で管理し、継続的に改善を行いながら、人とAIの双方が理解しやすい開発ドキュメントを整備することで、品質の高いコードを効率よく生成できる開発環境の構築を目指します。

---

## 2. コンセプト

以下のようなスターターキットを目指します。

- **人とAIの双方が理解しやすい開発ドキュメント**
- **専門的な役割を分担**し、一人でも小規模チームに近い開発体制を目指す
- シンプルで初学者にも理解・学習しやすい構成
- 継続的に改善・発展できるプロジェクト
- 保守性・拡張性を重視し、実務で採用しやすい設計・実装

### Version 1.0 — 公開できる最小完成物

**目指す状態**: 動く社員管理 CRUD を題材にした AI 協調リファレンスを、名称・ライセンス・セットアップ・最低限の体験付きで公開できる。

|区分|内容|
|---|---|
|機能|共通レイアウト、TOP、社員 CRUD、入力チェック、成功メッセージ（暫定）|
|公開体裁|正式名称、ライセンス、README／setup 導線、公開前 docs 整合、初見視点ウォークスルー|
|AI協調|現行の [`ai.md`](../02_rules/ai.md) と `prompts/` で運用できること（標準化はしない）|

作業の全量・進捗は [`progress.md`](progress.md) §6 を参照してください。

Version 1.0 は GitHub 等への公開を前提とします。コードは OSS とし、開発ドキュメント（`docs`）も公開します。AI 協調の試行記録など一部資料は非公開とします。リポジトリ本体の販売や機能の有料切り出しは行いません（詳細は [`public_offering_strategy.md`](../07_decisions/public_offering_strategy.md)）。

### Version 1.x — 実務で使いやすくする

Version 1.0 公開後の増分です。公開ブロッカーにはしません。

#### 機能追加

- CSV 入出力
- ファイルアップロード
- メール送信

#### 技術対応

- Spring Security
- Docker
- Spring Boot 4.x 対応（必要になった時点）

（Flyway は Version 1.x で導入済み。方針は [`flyway_adoption.md`](../07_decisions/flyway_adoption.md)、進捗は [`progress.md`](progress.md) の PRG-CMN-004）

#### 品質・標準化（軽いもの）

- メッセージ・例外方針の整備（暫定実装からの昇格）
- UI パターンの段階的共通化（2 画面目以降で回収）
- 社員番号の採番・形式・文字種の本決め、論理削除済みコード再利用方針の見直し（V1.0 は当面方針の明記のみ。BLG-EMP-007／013）
- 動作確認チェックリスト運用の定着、prompts の整理
- AI 向けルール・設計書テンプレートの継続改善
- AI 協調開発フローの再現性検証（小規模 CRUD。Version 2.x の標準化実証とも接続）

### Version 2.x — 再利用資産化

1 題材（社員管理）が固まったあとに抽出・標準化するテーマです。

- 共通基盤の抽出
- AI 協調開発フローの標準化（工程別標準プロンプト）
- AI 協調開発フローの再現性検証の継続・標準化への反映（1.x で着手した場合の知見を含む）
- 共通テンプレート化・他プロジェクトへの展開しやすさ
- 正式なテスト資料・テスト体系（`docs/08_test` 候補）
- Spring Boot / Java の最新版追随（大規模アップデート）
- 複数 AI による協調開発手法の確立

### Version 3.x — 拡張・対外展開

- デモサイト公開
- 教材・伴走など隣接サービスの検討
- AI 協調開発のコンテキスト設計実験の本格化
- AI を活用した業務システム開発のリファレンスとしての継続公開
