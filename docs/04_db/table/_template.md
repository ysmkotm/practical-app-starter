# テーブル定義書テンプレート

**Document Version** : 1.0

**更新日** : 2026/07/30

本テンプレートはテーブル定義書として利用します。

**基本方針**

- 「読み手が理解しやすいこと」を最優先とします。
- 同じ情報はできるだけ一か所で管理し、二重管理を避けます。

**テーブル定義方針**

- 1テーブルにつき1ファイルで管理します。
- 命名・共通カラムなどは [`docs/02_rules/db.md`](../../02_rules/db.md) に従います。

**テンプレート利用方法**

- 引用（>）で記載されている内容は説明・記載例です。実際の設計内容は引用の外側に記載し、説明・記載例は完成した設計書から削除してください。
- 必要に応じて、見出し・表・説明などを追加・修正・削除してください。

※テンプレートは実際の運用を通して継続的に改善してください。

## 2. カラム定義

|No|物理名|論理名|データ型|PK|FK|NOT NULL|初期値|備考|
|---|---|---|---|---|---|---|---|---|
|1||||||||

> データ型は、DDLで使用する型をそのまま記載してください。
> 桁数・精度が必要な型は、型名に含めて記載します（例：`VARCHAR(100)`、`NUMERIC(10,2)`）。
>
> 初期値は、DDLの`DEFAULT`に指定した値を記載してください（例：`FALSE`、`CURRENT_TIMESTAMP`）。
> `BIGSERIAL`など自動採番となるカラムは、初期値とは性質が異なるため初期値欄には記載せず、備考に「自動採番」と記載してください。
> 
> 共通コードを使用するカラムの備考には、共通コードマスタのテーブル名ではなく、コード種別（`code_type`の値）を記載してください。詳細は [`docs/02_rules/db.md`](../../02_rules/db.md) §4を参照してください。

> **記載例**
> 
> |No|物理名|論理名|データ型|PK|FK|NOT NULL|初期値|備考|
> |---|---|---|---|---|---|---|---|---|
> |1|employee_id|社員ID|BIGSERIAL|○||○||自動採番|
> |7|department_id|部署ID|BIGINT||○|○|||
> |10|status_code|在籍区分コード|VARCHAR(20)|||○||コード種別：`EMPLOYEE_STATUS`|
> |11|remote_work_flg|リモートワークフラグ|BOOLEAN|||○|FALSE||
> |14|created_at|作成日時|TIMESTAMP|||○|CURRENT_TIMESTAMP||
