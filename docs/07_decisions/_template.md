# 判断記録テンプレート

**Document Version** : 1.0

**更新日** : 2026/07/30

**ステータス** : 検討中 / 決定 / 保留 / 却下

本テンプレートは、プロジェクト内で参照したい判断事項や検討内容を記録する際に利用します。

実際の運用を通して継続的に改善してください。

【テンプレート利用方法】

- ファイル名は、判断内容が分かる名前にします（例：`project_name_candidates.md`）。
- 引用（`>`）で記載されている内容は説明・記載例です。実際の記録では削除または置き換えてください。
- 候補が多い場合は、§3 を小見出しで分割して構いません（比較優先案＋一覧など）。
- **検討中**：§5・§6 は未決定として記載します。
- **決定・保留・却下**：§5・§6 に判断結果とその理由を記載します。
