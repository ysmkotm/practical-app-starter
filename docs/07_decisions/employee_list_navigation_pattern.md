# 社員一覧の画面遷移方針（操作列廃止・社員番号リンク・削除の編集画面移管）

**Document Version** : 1.0

**更新日** : 2026/07/30

**ステータス** : 決定

---

## 1. 目的

EMP001 社員一覧の画面遷移・操作配置を見直し、一覧画面と登録・編集画面の責務分担を明確にする判断を記録する。

---

## 2. 背景

EMP001 の検索・一覧 GET 実装完了後、次タスクとして一覧からの削除 POST 実装を予定していた。画面遷移を整理した結果、次の方針変更が提案された。

- 一覧の操作列（詳細・編集・削除）を廃止する
- 社員番号をリンクとし、EMP002（社員登録・編集）の編集モードへ遷移する
- 更新・削除は EMP002 の編集画面から行う
- 独立した社員詳細画面は設けない
- 一覧画面の役割は「検索・一覧表示・対象選択」とする

当初の EMP001 設計書（v1.6）では、操作列に詳細・編集・削除ボタンを配置し、削除 POST を EMP001 のエントリポイントとしていた。詳細画面は一時 EMP003 として画面一覧に「保留」していたが、2026/07/29 に廃止した（本判断の追記）。

---

## 3. 検討した案

|案|概要|メリット|デメリット|
|---|---|---|---|
|A. 操作列維持（現設計）|一覧に詳細・編集・削除ボタンを配置。削除は EMP001 POST|一覧から直接操作できる。操作の存在が視覚的に明確|列が増え可読性が下がる。詳細画面が未実装の間、詳細ボタンが無効のまま残る|
|B. 社員番号リンク＋編集画面で更新・削除（採用）|一覧は選択のみ。社員番号クリックで EMP002 編集へ。削除は EMP002|一覧がシンプル。マスタ系画面で一般的。Version 1 スコープと整合|編集画面を開かないと削除できない|

---

## 4. 判断基準

- 業務システムとして実務で採用しやすい画面構成であること
- Version 1.0 の社員管理 CRUD 完成に必要十分であること
- 既存実装（EMP001 GET、Controller スタブ）との整合が取れること
- 編集画面完結の構成を正式な画面構成として維持できること

---

## 5. 判断結果

**案Bを採用**する。

|項目|決定内容|
|---|---|
|EMP001 操作列|廃止する|
|一覧からの遷移|社員番号リンク → `GET /employee/{employeeId}/edit`（EMP002 編集モード）|
|更新・削除|EMP002 の編集画面から行う（登録・更新・削除 POST は EMP002 に集約）|
|社員詳細画面|設けない。かつての EMP003（保留）は廃止し、画面一覧から削除する|
|社員番号リンクの有効化|EMP002 GET 実装まで `disabled` 表示とする|
|詳細用 Controller スタブ|`EmployeeController#showDetail`（`GET /employee/{employeeId}`）は削除する|

---

## 6. 判断理由

- 一覧画面の責務を「検索・一覧表示・対象選択」に限定することで、画面の目的が明確になる。
- 操作列の削除により DataTables 一覧の列数が減り、社員番号・氏名・部署等の業務情報の可読性が向上する。
- 更新・削除を編集画面に集約する構成は、マスタ管理画面で広く使われており、学習・リファレンス目的の本プロジェクトにも適合する。
- 編集画面で社員情報の参照・更新・削除が完結するため、独立した詳細画面がなくても CRUD の完成条件を満たせる。
- ロードマップ上も社員詳細は必須ではなく、「保留」として ID を予約し続ける合理性が薄いため廃止する。将来必要になった場合は、その時点で新規画面として設計する。
- 未実装の `showDetail` スタブを残すと、設計と実装が乖離するため削除する（[`docs/02_rules/coding.md`](../02_rules/coding.md) §7「未実装メソッドの残し方」に沿う）。

---

## 7. 今後の対応

- EMP001 設計書・EMP002 設計書（新規）・関連ドキュメントを本判断に合わせて更新する。
- EMP001 実装では操作列を削除し、社員番号をリンク表示とする（EMP002 GET 実装まで `disabled`）。
- EMP002 設計書承認後、GET・POST（登録・更新・削除）を実装する。
- 一覧から編集画面へ遷移し、戻る際に検索条件を保持するかは EMP002 設計書の遷移仕様で定義する。
- EMP002 編集モードでは、社員番号は読み取り専用とする。一覧の社員番号リンクが編集画面への入口であるため、識別コードとしての役割を明確にする（[`EMP002_社員登録・編集.md`](../05_screen/EMP002_社員登録・編集.md) §5.2）。
- （追記 2026/07/29）EMP003 を画面一覧・機能一覧から削除し、関連表現を「廃止」に揃える。
