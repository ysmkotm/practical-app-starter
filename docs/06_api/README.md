# API設計書

**Document Version** : 1.0

**更新日** : 2026/07/30

---

## 1. 概要

本フォルダは、API単位の設計内容を管理します。

Version 1.0 時点では、本プロジェクトは画面（Thymeleaf）主体の構成であり、設計対象となる API はありません。そのため API設計書は配置していません。

---

## 2. 今後の扱い

- API を追加する時点で、本フォルダへ API単位の設計書を作成します。
- 記載構成のテンプレートも、最初の API を設計する時点で整備します。運用していない標準を先に作らないためです（[`docs/07_decisions/version1_publish_scope.md`](../07_decisions/version1_publish_scope.md) §4）。
