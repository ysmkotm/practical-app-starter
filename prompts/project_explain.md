# プロジェクトの説明依頼

## 使い方

リポジトリをクローンし、セットアップした直後に「何のプロジェクトか」を把握したいときに使います。下の依頼文をコピーしてください。

---

## 依頼文

```text
このリポジトリをクローンしてセットアップしたばかりです。

README と開発ドキュメントを根拠に、次を短く説明してください。

1. このプロジェクトは何か（目的・位置づけ）
2. Version 1.0 で何ができるか
3. いま最初に読む・触るべき場所（優先順位付き、最大5つ）
4. このスターターで特に注目すべき点（AI協調・開発ドキュメントなど）

推測ではなく、リポジトリ内の文書を根拠にしてください。
長くなりすぎないよう、全体で読みやすい分量にしてください。
```

---

## 補足（依頼時に足すとよい情報）

- 自分の目的（学習／起動確認／改修の土台など）
- すでに読んだファイルがあればその旨
