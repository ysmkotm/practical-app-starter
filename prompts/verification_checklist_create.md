# 動作確認チェックリスト作成依頼

## 使い方

[`progress.md`](../docs/01_project/progress.md) の PRG 作業に対し、動作確認チェックリストの作成を依頼するときに使います。下の依頼文をコピーしてください。

---

## 依頼文

```text
PRG-{ID} の動作確認工程向けに、動作確認チェックリストを作成してください。

前提：
- 仕様の正本は画面設計書・判断記録・DB 設計書等。チェックリストは作業補助であり SSOT にしない
- progress にはリンクまたはパス表記のみ（本文は置かない）
- 意図的保留（backlog の保留・暫定実装）は「見なくてよいもの」として明示する
- 必須 / 任意を分け、完了判定条件を書く
- 結果列は未確認 `-`、OK、NG（NG 時はメモ）とする（[x] は使わない）
- 用語は設計書・テーブル定義に合わせる（例：在籍区分は共通コードマスタ）

参照してほしいもの：
- progress の当該 PRG
- 関連する画面設計書
- 関連する backlog / decisions
- 必要なら実装のエントリポイント

保存先の提案：
- 本体は `private/verification/`（作業正本。依頼文用の prompts には置かない）
- Version 1.0 ではチェックリスト本体は公開しない（公開 docs からはパス表記のみ）
- 作成後、progress 作業メモからパス表記で参照する

作成後はコミット準備案を提示してください（ファイルを変更した場合）。
```

---

## 補足（依頼時に足すとよい情報）

- Tier（L / M）と、なぜチェックリストが必要か（通し観点・保留の多さなど）
- 画面 ID・URL
- 特に見てほしいシナリオ（削除済みマスタ、一意性など）
