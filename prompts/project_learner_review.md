# 学習者向けプロジェクトレビュー依頼

## 使い方

セットアップ後、学習者の視点でリポジトリのわかりやすさや改善点を聞きたいときに使います。公開前のメンテ用レビューではありません。下の依頼文をコピーしてください。

---

## 依頼文

```text
このリポジトリをクローンしてセットアップした学習者の視点で、プロジェクトをレビューしてください。

目的は「公開ブロッカーの洗い出し」ではなく、初めて触る人が理解・学習しやすい状態かの確認です。
ファイルは編集せず、指摘と改善案のみ提示してください。

次の観点で見てください。

1. 入口（README・setup・docs 索引）は迷わず辿れるか
2. 目的・対象者・前提が伝わるか
3. 動かし方と、動いたあとの次の一歩が分かるか
4. 開発ドキュメントとプロンプトの役割は初見でも分かるか
5. わかりにくい・足りない・冗長なところ

出力イメージ：
- 良い点（簡潔に）
- 気になる点（重要度つき）
- 学習者が次にやるとよいこと（1〜3個）

推測ではなく、確認できた文書・構成を根拠にしてください。
```

## 補足（依頼時に足すとよい情報）

- 自分の経験レベル（Java / Spring Boot / AI 利用の慣れ）
- 特に見てほしい場所（README、setup、docs など）
